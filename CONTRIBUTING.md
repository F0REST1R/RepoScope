# Участие в разработке RepoScope

1. Создайте ветку от `main`: `git switch -c feature/short-name`.
2. Скопируйте `.env.example` в `.env`, не добавляйте токены и пароли в Git.
3. Перед коммитом выполните `make fmt`, `make test`, `make frontend-build`.
4. Для изменения API сначала обновите обработчик и тесты, затем `docs/openapi.yaml`, Postman и cURL-примеры.
5. Коммит должен быть небольшим и описывать причину изменения. В pull request укажите сценарий проверки.

Сообщить об ошибке можно issue с шагами воспроизведения, ожидаемым и фактическим результатом, ОС и версией браузера/Go. Не публикуйте секреты и персональные данные.
